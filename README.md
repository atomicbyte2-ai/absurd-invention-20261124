# Absurd Invention — The Parachute Toaster

One-sentence absurd invention pitch for the make.fun bounty
[One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

The pitch: a toaster that launches every slice under a tiny parachute, so your
toast can never land butter-side down no matter how clumsy your morning is.

Running `main.ts` writes the single sentence (150 characters) to
`/output/entry.txt`.
